This folder is a safe copy of hosted browser review metadata. Raw job logs,
archives, Playwright blobs, authenticated browser state, and screenshots remain
private under `.cache/terra-shipping/parent/hosted-2bdf4708-browser-review/private/`.

`SHA256SUMS` hashes every retained evidence file by relative path; it excludes
only itself.

`artifact-byte-mapping.tsv` maps only reported artifact IDs, sizes, and
reported digests. It contains no archive bytes.
