## Dedicated assurance limits

- No candidate-specific penetration campaign was found. Rootless escape resistance is covered by focused integration probes, not a general penetration assessment.
- No sustained-load result for this candidate was found. Concurrency, quotas, PID/memory limits, and lock serialization have bounded tests; they do not establish long-duration capacity.
- Prior controlled fault-injection receipts cover selected service authority defects on earlier trees. They cannot be attributed to the final candidate. The current invocation defect has preserved red/green regression evidence.
- Rootless containers share the host kernel. A hostile host administrator and unknown kernel vulnerabilities are outside this boundary.
- Trusted-local mode has reduced isolation and must remain an explicit reviewed exception.
- A grant combining raw-secret access with approved egress permits disclosure.
- Cancellation and database rollback cannot undo an external effect that was already admitted.
