ROOT CAUSE (end to end on W19a's own harness, proof/w01h-base-fault, graph/base-fault.*)
  1. The attempt authority deadline is sealed to the first pool lease deadline, 30 s after admission
     (pool/ledger.ts leaseMs). The remote runtime never renews it. Under load the prepare guest outlives it;
     the host runner kills it at the deadline (podman stop + died 137).
  2. Host: result() ignored its abort, deleted the answer in `finally`, answered a bare 500/409, logged
     nothing (empty supervisor log).
  3. Product: the launch client used a 30 s timeout for every call, and under Bun 1.3.14 the transport
     never rejected on timeout or abort (node:https emits only `close`); remote runtime threw before
     recordTerminal and never stopped the guest; the dispatcher swallowed the error (`catch {}`) and parked
     the queue row outcome_unknown. No terminal row, no task outcome, so no `node-failed`: the kernel waits
     for its own node/run deadline (10 min here).
  4. At the run deadline the kernel's stop moves only the kernel epoch; the durable fence epoch moves only
     on a user cancel, so cancel-node is refused factory_command_stale and the run holds in `stopping`
     (second defect; probe/zz-w01h-deadline-stop.scratch.test.ts). Not fixed here; reported.
  5. Even with the fix, C02 refuses any report for an attempt past its deadline
     (run-lifecycle authorizeAttemptInTransaction: deadlineAt <= now -> factory_run_fence_changed), so a
     guest that dies AT its deadline can never reach the kernel as node-failed. Ruling requested
     (proposal-report-after-deadline.patch).

FIX (what W01h changes)
  - transport: rejects on deadline, abort, close-before-response, early response close, oversize, under Bun.
  - host: keeps a settled answer 15 min, every read returns it; 20 s long-poll window (504 host_timeout);
    guest_exited (502, runner diagnostics) and attempt_unknown (409) refusals; every refusal one JSON line
    in the supervisor log; a start is joined, never doubled; first-hand stop knowledge only from a guest that
    settled on this host.
  - product: bounded long poll; every lost answer recorded `failed` over the journal's own facts after a
    best-effort stop: RUNNER_CONTAINER_EXIT / RUNNER_SUPERVISOR_LOST (409 or 120 s silence) /
    RUNNER_TIMEOUT (deadline + 30 s); waits up to 300 s for in-flight journal operations; unconfirmed launch
    collected the same way; client timeout 90 s; the dispatcher keeps the runner's error as the cause.
