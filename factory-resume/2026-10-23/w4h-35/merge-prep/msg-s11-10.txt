test(web): the GitHub device-code e2e takes its expiry from the page clock

Hosted ci 39956956620 failed web/e2e/personal-github-settings.spec.ts:208 on every run: the device code was not shown. The test fixes
the page clock at 2026-09-23 but gave the code an expiry from the runner's real clock. Since 2026-10-18T08:21Z that expiry is more
than 2^31-1 ms ahead of the page clock, and Playwright's clock fires such a timer after 1 ms, so the code expired at once.

The test now sets the expiry ten minutes after the page clock start, which the sibling clock test shares.
